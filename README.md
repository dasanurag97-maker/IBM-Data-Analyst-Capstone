## 📌 Project Overview

An end-to-end data analytics project analyzing **Tesla (TSLA)** and **GameStop (GME)** historical stock prices and quarterly revenue data. This project demonstrates:

- Data extraction via **yfinance API** and **web scraping**
- Data cleaning & wrangling with **Pandas**
- Exploratory data analysis (EDA)
- Interactive dashboard visualizations using **Plotly**

---

## 🔍 Key Insights

### Tesla (TSLA) — 2018 to 2021
- Both stock price and revenue showed **strong synchronized upward growth**
- Revenue grew **5× from ~$2B in 2018 to over $10B in 2021**
- Stock price surged from ~$18 to **$299** — driven by genuine business performance

### GameStop (GME) — 2021 Short Squeeze
- Stock price **spiked from ~$4 to $80+** in January 2021
- Revenue was **declining** throughout this period
- A textbook case of **speculative trading completely decoupled from business fundamentals** (Reddit/WallStreetBets short squeeze)

## 🚀 How to Run

### 1. Clone the repository
```bash
git clone https://github.com/dasanurag97-maker/stock-revenue-dashboard
cd stock-revenue-dashboard
```

### 2. Install dependencies
```bash
pip install yfinance beautifulsoup4 requests pandas plotly notebook
```

### 3. Launch Jupyter Notebook
```bash
jupyter notebook Analyzing_Historical_Stock_Revenue_Dashboard.ipynb
```

### 4. Run all cells
Click **Run All** to execute the full pipeline — data extraction → cleaning → visualization.
