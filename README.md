# Analyzing Historical Stock & Revenue Dashboard

IBM Data Analyst Professional Certificate — Capstone Project

## Overview
Analyzed Tesla (TSLA) and GameStop (GME) historical stock 
and revenue data using Python, web scraping, and Plotly 
to build an interactive dashboard.

## Tools & Skills
- Python (Pandas, NumPy)
- yfinance API
- BeautifulSoup (Web Scraping)
- Plotly (Interactive Charts)
- Jupyter Notebook

## Dashboard includes
- Tesla Historical Share Price & Revenue (2010–2021)
- GameStop Historical Share Price & Revenue (2002–2021)
